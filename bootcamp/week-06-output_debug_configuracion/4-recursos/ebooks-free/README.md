# Libros gratuitos — Semana 06

_Comprobado el 10 de noviembre de 2026._

## Libros

| Recurso | Por qué vale la pena |
|---|---|
| [everything.curl.dev — Verbose](https://everything.curl.dev/usingcurl/verbose/) | El capítulo del libro oficial sobre `-v`, `--trace` y `--write-out`, escrito por el autor de curl. La teoría 05 y la 06 condensan estas páginas |
| [everything.curl.dev — Config file](https://everything.curl.dev/cmdline/configfile.html) | La sintaxis del `.curlrc` y del `-K`, con los casos raros: comillas, `url =`, líneas largas |
| [everything.curl.dev — Variables](https://everything.curl.dev/cmdline/variables) | `--variable` y `--expand-*` (8.3+), con las funciones `trim`, `json`, `url` y `b64` |
| [Google SRE Book — Monitoring Distributed Systems](https://sre.google/sre-book/monitoring-distributed-systems/) | Las "cuatro señales doradas" (latencia, tráfico, errores, saturación) y por qué se mide el percentil y no la media. Es el porqué de la práctica 04 |
| [Google SRE Workbook — Implementing SLOs](https://sre.google/workbook/implementing-slos/) | Cómo pasar de "va lento" a un objetivo medible con p95 y tasa de error. Para cuando las métricas del toolkit tengan que servir de algo |
| [High Performance Browser Networking — Building Blocks of TCP](https://hpbn.co/building-blocks-of-tcp/) | Por qué la fase tcp crece con la distancia y no con el ancho de banda. Explica lo que `time_connect` mide |
