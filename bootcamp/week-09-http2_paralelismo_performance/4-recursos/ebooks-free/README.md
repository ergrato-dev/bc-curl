# Libros gratuitos — Semana 09

_Comprobado el 11 de noviembre de 2026._

## Libros

| Recurso | Por qué vale la pena |
|---|---|
| [High Performance Browser Networking — Ilya Grigorik](https://hpbn.co/) | El libro de referencia sobre rendimiento de red, gratis en la web. Pensado para navegadores, pero los capítulos de latencia, TCP, TLS y HTTP/2 valen igual para un script |
| [HPBN — Primer on Latency and Bandwidth](https://hpbn.co/primer-on-latency-and-bandwidth/) | Por qué la latencia manda y el ancho de banda casi no, con números. Es la teoría 01 explicada a fondo |
| [HPBN — Building Blocks of TCP](https://hpbn.co/building-blocks-of-tcp/) | El saludo de tres pasos, el arranque lento y por qué una conexión reutilizada va más rápido que una nueva aunque el servidor sea el mismo |
| [HPBN — HTTP/1.X](https://hpbn.co/http1x/) | Keep-alive, pipelining y por qué los navegadores abren seis conexiones por host. El problema que HTTP/2 vino a resolver |
| [HPBN — HTTP/2](https://hpbn.co/http2/) | Frames, streams, multiplexación, HPACK y control de flujo, con diagramas. Complementa la teoría 03 |
| [http2 explained — Daniel Stenberg](https://daniel.haxx.se/http2/) | Del autor de curl: HTTP/2 en un librito corto, con el porqué de cada decisión de diseño |
| [HTTP/3 explained — Daniel Stenberg](https://http3-explained.haxx.se/) | Lo mismo para QUIC y HTTP/3: qué arregla de TCP, por qué UDP y qué cuesta desplegarlo. La teoría 07 en profundidad |
| [everything.curl.dev — Parallel transfers](https://everything.curl.dev/cmdline/urls/parallel.html) | El capítulo del libro oficial de curl sobre `-Z` y `--parallel-max`. Corto, con ejemplos |
| [everything.curl.dev — Connection reuse](https://everything.curl.dev/transfers/conn/reuse.html) | Cuándo reutiliza curl una conexión y cuándo no: el pool, el host, el puerto y el esquema |
