# Documentación del bootcamp

de su semana.

## Orden de lectura antes de la Semana 01

1. [setup-entorno.md](setup-entorno.md) — sin el laboratorio arriba, la primera práctica no arranca
2. [versiones-de-curl.md](versiones-de-curl.md) — comprueba tu versión antes de que un ejemplo falle por eso
3. [proyecto-hilo-conductor.md](proyecto-hilo-conductor.md) — elige tu dominio, porque lo arrastras diez semanas
4. [autograding.md](autograding.md) — para saber cómo se te evalúa

Vuelve a [trucos-curl.md](trucos-curl.md) al terminar cada semana: crece contigo.
